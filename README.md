# مخزن مطعم فرايدي

نظام مخزن لمطعم فرايدي: React + Vite + TypeScript + Tailwind + shadcn/ui، عربي RTL، PWA، Firebase (Firestore + Authentication).

- الرابط: https://fryday-stock.github.io/fryday-store/
- بدون إعدادات Firebase بـ `src/config.ts` يشتغل **وضع تجربة** (البيانات على نفس الجهاز).
- خطوات ربط Firebase: [docs/FIREBASE.md](docs/FIREBASE.md)
- شرح كامل للمشروع: [CLAUDE.md](CLAUDE.md)

```bash
npm install
npm run dev
npm run build
```
